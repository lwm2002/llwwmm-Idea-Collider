# Idea Collider · 概念碰撞实验室

一个可以直接在本地玩的跨领域创意工作台。选择两个概念，观察连接图谱，生成发明，持续演化，再用 Critic 质疑它。没有账号要求；没有 API Key 也能体验完整闭环。

## 运行

环境：Node.js 20.19+ 或 22.12+（已在 Windows、Node 24 和 Microsoft Edge 实测）。

```powershell
cd D:\codex\game
npm install
npm run dev -- --port 5173 --strictPort
```

打开 **http://127.0.0.1:5173/**。终端中按 `Ctrl+C` 停止服务器。

也可以双击当前目录的 `start.cmd`，它会检查依赖并启动本地服务器。首次安装依赖需要联网；安装后，本地生成模式不需要外网。服务器只监听本机地址。

关闭时可以双击 `stop.cmd`。脚本检查 5173 端口，只停止命令行能够确认为本项目的 Vite 进程；未启动时会直接提示无需关闭，其他程序占用端口时不会强制结束。遇到“Port 5173 is already in use”时，先运行关闭脚本，再双击 `start.cmd`。

```powershell
npm run lint          # ESLint
npm run test          # Vitest：数据、随机距离、离线闭环、API校验、持久化
npm run test:e2e      # Playwright：默认使用已安装的 Microsoft Edge
npm run build         # TypeScript 检查 + Vite 生产构建
npm run preview       # 本地预览构建产物，默认端口 4173
```

`npm run test:e2e` 会自动启动或复用 5173 端口的开发服务器。截图保存在 `test-results/`。在没有 Edge 的其他系统上，运行 `npx playwright install chromium`，再将 `playwright.config.ts` 的 `channel: 'msedge'` 改为 `channel: 'chromium'`。

## 试一次完整实验

1. 首页默认 **蜂群 × 金刚石**。点击 **COLLIDE**，观察四步碰撞过程。
2. 在关系图上拖动节点，点击一个连接，例如“分布式缺陷传感网络”。图下方的连接卡也可点击。
3. 得到实用型、探索型、荒诞型三张发明卡；展开查看问题、机制、两侧贡献、实现路径和局限。
4. 点击 **EVOLVE**，尝试“更便宜”“去掉AI”“加入机械结构”等变异。
5. 点击 **CHALLENGE** 查看主要问题、次要问题、潜在修复与结论。
6. 点击星标收藏。到 **Favorites** 重新打开；到 **History** 查看全部实验及演化版本。

## AI 设置

打开右上角 **Settings**，填写：

填写服务商地址和 Key 后，直接点击 **“测试连接 / 获取模型”**，无需先填写 Model Name，也无需先保存。应用使用当前表单配置请求 `GET /models`，展示服务实际返回的列表，支持筛选和选择。未提供标准模型列表的服务，可手动填写模型名。不会用内置假列表冒充已验证的模型，也不会把 Key 发送给其他平台尝试识别。

选择模型后，点击 **“验证模型生成”**，发送一次小型生成请求（可能产生服务商费用），检查该模型能否返回有效 JSON。模型列表成功不代表其中每个模型都支持文字生成或当前账户都有调用权限。最后保存设置并开启 AI。

生成接口支持 `POST /chat/completions`、`messages` 与 `choices[0].message.content`。默认使用 `response_format: { type: 'json_object' }`；服务不支持此参数时，可在“兼容性设置”关闭“请求 JSON 模式”，但仍要求模型输出 JSON，并使用 Zod 对数量、类型、必填字段和评分范围再次校验；无效数据不会进入工作区。

AI 生成默认最多等待 180 秒，可在 Settings 的“AI 最长等待时间（秒）”调整为 30–600 秒；模型列表查询最多等待 20 秒。计时覆盖连接和完整响应内容读取，超时、取消、输出截断和返回字段不完整会分别提示。碰撞生成中可取消，离开页面会终止当前请求。失败可重试或明确选择“改用离线生成”。不会在后台悄悄把离线内容标记成 AI 结果。模型地址和认证是否可用取决于你的服务；本项目未使用真实个人密钥请求付费模型，兼容接口通过模拟响应及错误场景测试。

COLLIDE 按连接逐条校验，保留具备完整依据和必要内容的结果，过滤内容不完整或重复的条目。评分兼容数字字符串、百分数和明确的 5/10/100 分制表示；缺失、超范围或无法识别时保留连接并显示“未评分”，不会填造默认分数，也不会将空评分当作零分参与离线发明或演化。数量、维度或属性多样性不足会显示提示，并允许继续探索；不再因此拒绝整批有效结果。全部内容无效时说明具体字段，并保留重试和离线回退入口。图谱节点用摘要显示长文本，完整定义保留在连接详情中。

生成提示要求简明说明机制、场景与验证方法，以减少输出负担。页面显示已等待秒数，等待超过 30 秒时可直接停止当前请求并改用离线生成；结果返回后直接显示图谱，不再额外等待动画。

请求直接由浏览器发往你配置的服务。服务需要支持浏览器跨域（CORS）。如果服务不支持，应使用你自己的本机兼容代理，再将 Base URL 指向该代理；本版没有内置服务端代理。

按照需求，API Key 保存在当前浏览器的 **localStorage（明文）**，不会写入源码或工作区导出文件。只在可信个人设备上填写。导入备份保留当前浏览器的 API 设置，不从文件载入 Key。

兼容格式参考：[OpenAI Structured Outputs / JSON mode](https://developers.openai.com/api/docs/guides/structured-outputs)。本项目选择 JSON mode 以适配更多兼容服务，返回值必须再通过应用侧校验。

## 本地生成的边界

本地引擎使用概念属性、功能、约束和多种机制映射策略，组合场景并生成不同方向。默认蜂群与金刚石案例含专门编写的连接及原型方案。其他组合属于规则与模板驱动的创意草案，语义深度仍有限；启用模型可以扩展表达与推理。

文本区分已有知识与创意假设。评分是内部玩法指标，**不是科学结论、专利新颖性、医疗建议或工程可行性保证**。Critic 没有执行实时市场或专利检索。

## 数据与备份

- 数据键：`idea-collider:v1`，带有版本及结构校验。
- 收藏、碰撞、Idea 版本及 Critic 自动保存。存储被禁用或已满时，会显示未能持久保存的提示。

- 清除浏览器网站数据会删除工作区。可先在 Settings 导出 JSON；导出不含密钥。
- 导入会验证概念、谱系和关联记录，拒绝同一碰撞内重复的连接 ID；先展示备份数量，再由用户确认替换。备份大小限制 5 MB。重新选择文件会清除旧确认，较早文件的迟到读取结果不会覆盖最新选择。
- 不上传工作区，不提供账号或云同步。

### 2026-10-07 自由概念、独立解释与持续探索

- 工作台 A/B 卡片可输入任意概念，按 Enter 创建；概念库也有“创建概念”入口。已有名称直接复用。可先用 AI 拆解，再审阅修改定义、具体属性、用途和限制。
- 每个概念均可单独查看解释。启用 API 后点击“AI 深入解释每项属性”，获得定义、运作原理、例子、与相近概念的区别和逐项属性解释。按概念保存结果，刷新与备份可恢复。
- 首批连接可选 4、8、12 条，默认 8 条；结果页“继续探索新连接”可追加，自动过滤同标题及同属性配对同维度的结果，不覆盖原连接和发明。语义近似仍需要人工判断。图谱每页展示 8 条，单次实验最多保存 500 条。
- AI 不再局限于内置属性列表，从结构、行为、时间、信息、社会、空间、能量、体验等角度探索；输出至少覆盖四个维度，每侧至少三个不同特征，并解释依据和反证方式。
- 属性依据区分已知特征、用户定义与推测。模型判断不等于外部事实验证；结构校验能拦截缺失与重复，不能证明语义正确或创意有价值。
- 离线模式按已有具体属性选择探索角度，仍是规则引擎。陌生概念只有名称时明确显示待补充，不伪造百科知识。填写补充定义可形成用户定义属性。候选耗尽时会提示，不重复填满数量。
- 自定义概念进入搜索、随机配对、图谱、发明、演化、收藏与备份。兼容旧备份与原有五条连接记录。旧结果不会自动重写，可创建新碰撞或追加探索。
- 本轮浏览器 API 测试使用受控模拟响应；没有读取或使用用户真实密钥，也没有逐一实测所有供应商。
